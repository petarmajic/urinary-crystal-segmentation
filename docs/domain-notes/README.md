# Domain reference notes

These original documents explain the source collection and terminology. The French notes are the primary domain references; Croatian notes are retained as working material, rather than substituted for the original terminology.

| Document | Use |
| --- | --- |
| [Initial dataset review, French](initial-dataset-review-fr.docx) | Questions and expert responses about mixtures, folder reliability, morphology, lighting, resolution and image relationships |
| [Crystal coding guide, French](crystal-coding-guide-fr.docx) | Species codes and filename abbreviations used to construct metadata mappings |
| [Crystal coding notes, Croatian](crystal-coding-notes-hr.docx) | Working translation/reference; some translated names differ from the French codes |
| [Dataset organisation notes, Croatian](dataset-organisation-notes-hr.docx) | Working translation of the dataset discussion |

Filename clues are useful metadata, but the manual polygon labels are the training ground truth. Proposed uses of pH or acquisition information in the notes do not establish that these features were used as model inputs.
